## 🎯 Overview
A comprehensive face recognition security system with multiple authentication methods, real-time monitoring, and intruder alert capabilities. Built with Python, OpenCV, and Flask.

## ✨ Features

### 🔐 Multi-Factor Authentication
- **Face Recognition** - Primary biometric authentication
- **Password Fallback** - Traditional password authentication
- **Voice Command** - Voice-based access control
- **QR Code** - Quick authentication via QR codes

### 🛡️ Security Features
- **Intruder Detection** - Automatic photo capture of unauthorized access
- **Email Alerts** - Instant notifications with intruder photos
- **System Lockdown** - Automatic lockdown after multiple failed attempts
- **Real-time Monitoring** - Continuous security monitoring

### 🌐 Web Interface
- **Responsive Dashboard** - Beautiful web interface
- **Live Camera Feed** - Real-time video streaming
- **Admin Panel** - User management and system control
- **API Endpoints** - RESTful API for integration
